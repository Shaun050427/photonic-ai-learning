三、正确的学习方法

每个模块都用同样的五步学习法：

  1. 先形成直觉：它在物理上发生了什么？
  2. 再看数学：这个物理过程对应什么算子？
  3. 再看代码：怎样用 NumPy / PyTorch 写出来？
  4. 再做实验：改变参数后图像怎样变化？
  5. 最后接论文：论文在哪个环节做了创新？
不要一开始直接上 LightGen、Stable Diffusion 或完整 FDTD。先自己做一个最小传播器，再做 D2NN，再进入生成模型。

四、光场与复振幅

1. 为什么用复数描述光？

真实电场可以写成：

\[ E(x,y,z,t)=A(x,y,z)\cos(\omega t+\phi(x,y,z)) \]

为了计算方便，通常用复数形式：

\[ \boxed{U(x,y,z)=A(x,y,z)e^{i\phi(x,y,z)}} \]

这里：

  • \(A\)：振幅 amplitude
  • \(\phi\)：相位 phase
  • \(U\)：复光场 complex optical field

2. 相机实际测到什么？

\[ \boxed{I=|U|^2=A^2} \]

相机通常不能直接看到 phase，只能看到 intensity。 所以光学系统内部天然处理的是复数信息，但普通探测器最后只把它投影成强度。

科研直觉：电子神经网络通常处理实数，而光学系统天然处理复数。Amplitude 和 phase 都可以承载信息。

五、干涉：为什么“相位”能改变亮暗

两束光：

\[ U_1=Ae^{i\phi_1},\qquad U_2=Ae^{i\phi_2} \]

叠加后：

\[ U=U_1+U_2 \]

探测强度：

\[ I=|U_1+U_2|^2 =|U_1|^2+|U_2|^2+2A^2\cos(\phi_1-\phi_2) \]

关键就是：

\[ \boxed{2A^2\cos(\Delta\phi)} \]

因此即使两束光振幅完全一样，只要相位不同，最终输出就可能从“最亮”变成“完全抵消”。

最重要直觉：光学计算不是简单地“把亮度相加”，而是先把复振幅相加，再取平方得到强度。

六、衍射与传播：光为什么能“做计算”

设输入平面光场为 \(U_0(x,y)\)，传播距离 \(z\) 后为：

\[ \boxed{U_z=\mathcal{P}_z(U_0)} \]

\(\mathcal{P}_z\) 是传播算子。它本身就是一个线性算子。

神经网络一层：

\[ x_{l+1}=W_lx_l \]

光传播：

\[ U_{l+1}=\mathcal{P}_zU_l \]

因此，自由空间传播本质上已经是一种线性计算。

Huygens–Fresnel 直觉

把波面上的每一个点看成一个新的小球面波源，那么下一平面上的任意一点，都是前一平面所有点贡献的叠加。

\[ U(x,y,z)=\iint U(x',y',0)\,h(x-x',y-y',z)\,dx'dy' \]

这就是卷积：

\[ \boxed{U_z=U_0*h_z} \]
所以自由空间传播和信号处理、CNN 会天然联系起来：传播本身就是一种卷积型线性变换。

七、Fresnel 衍射

在近轴近似下，Fresnel propagation 可写成：

\[ U(x,y,z)= \frac{e^{ikz}}{i\lambda z} \iint U(x',y',0) \exp\left[ \frac{ik}{2z} \left((x-x')^2+(y-y')^2\right) \right] dx'dy' \]

其中：

\[ k=\frac{2\pi}{\lambda} \]

定义 Fresnel impulse response：

\[ h_z(x,y)= \frac{e^{ikz}}{i\lambda z} \exp\left[ \frac{ik}{2z}(x^2+y^2) \right] \]

于是：

\[ \boxed{U_z=U_0*h_z} \]

D2NN 一层是什么？

phase mask：

\[ T_l(x,y)=e^{i\phi_l(x,y)} \]

先调相：

\[ U'_l=U_lT_l \]

再传播：

\[ \boxed{U_{l+1}=\mathcal P_z\left[U_le^{i\phi_l}\right]} \]
Field ↓ Phase Mask ↓ Propagation ↓ Phase Mask ↓ Propagation ↓ Detector
D2NN 的核心并不神秘：反复执行“相位调制 + 传播”。

八、Fraunhofer 衍射：为什么远场是傅里叶变换

当传播距离足够远时，Fresnel 模型进一步简化：

\[ \boxed{U(x,y,z)\propto \mathcal F\{U(x',y')\}} \]

也就是说：

\[ \boxed{\text{Far-field diffraction} \approx \text{Fourier transform}} \]

经典例子：单缝

如果输入孔径：

\[ U(x)=\operatorname{rect}\left(\frac{x}{a}\right) \]

傅里叶变换：

\[ \mathcal F\{\operatorname{rect}(x/a)\} =a\,\operatorname{sinc}(af_x) \]

远场强度：

\[ I\propto \operatorname{sinc}^2(af_x) \]
单缝衍射条纹，本质上就是“矩形孔径的 Fourier transform”。

十、透镜与 4f 系统

理想薄透镜引入二次相位：

\[ \boxed{ T_{\mathrm{lens}}(x,y)= \exp\left[-i\frac{k}{2f}(x^2+y^2)\right] } \]

如果输入位于前焦面，则后焦面近似得到：

\[ \boxed{U_f(x,y)\propto\mathcal F\{U_0\}} \]

所以透镜可以物理执行二维 Fourier transform。

4f 系统

Object │ f Lens 1 │ f Fourier Plane │ f Lens 2 │ f Image Plane

数学上：

\[ \boxed{ U_{\mathrm{out}}= \mathcal F^{-1}\left[ H\,\mathcal F(U_{\mathrm{in}}) \right] } \]

根据卷积定理：

\[ y=h*x \quad\Longleftrightarrow\quad \mathcal F(y)=\mathcal F(h)\mathcal F(x) \]
所以 4f 系统天然可以被理解成一个 optical convolution engine。

十一、Angular Spectrum Method（ASM）

任意复杂光场都可以分解成许多平面波：

\[ U(x,y)= \iint A(f_x,f_y) e^{i2\pi(f_xx+f_yy)} df_xdf_y \]

其中：

\[ A(f_x,f_y)=\mathcal F[U(x,y)] \]

每个频率分量传播 \(z\) 后乘上传播相位：

\[ H(f_x,f_y,z)=e^{ik_zz} \]

其中：

\[ k_z=\sqrt{k^2-k_x^2-k_y^2} \]

最终：

\[ \boxed{ U_z= \mathcal F^{-1} \left\{ \mathcal F(U_0)\,H_z \right\} } \]

U_fft = U_fft * H
U_z   = torch.fft.ifft2(U_fft)

十二、相位掩膜、SLM 与“光学权重”

光学网络里的可训练参数，经常不是一个普通矩阵，而是相位分布：

\[ \phi(x,y) \]

phase-only mask 对光场执行：

\[ \boxed{U_{\mathrm{out}}=U_{\mathrm{in}}e^{i\phi(x,y)}} \]

因为：

\[ |e^{i\phi}|=1 \]

所以理想 phase mask 不直接改变强度，只改变 phase。

但传播以后：

phase modulation ↓ propagation ↓ interference ↓ intensity redistribution

因此可以通过控制相位，间接控制最终 detector 上的亮暗分布。

D2NN 的本质不是“直接决定哪个像素亮”，而是控制不同路径在输出处怎样相长或相消干涉。

十三、MZI：集成光子芯片如何做矩阵乘

Mach–Zehnder Interferometer（MZI）由分束器、两条路径和相位调制器组成。

┌── phase φ1 ──┐ Input ─ BS BS ─ Output └── phase φ2 ──┘

通过控制相位差：

\[ \Delta\phi=\phi_1-\phi_2 \]

可以实现类似二维旋转：

\[ R(\theta)= \begin{bmatrix} \cos\theta & -\sin\theta\\ \sin\theta & \cos\theta \end{bmatrix} \]

许多 MZI 组成 mesh 后，可以通过矩阵分解实现：

\[ W=U\Sigma V^\dagger \]

从而执行：

\[ \boxed{y=Wx} \]

十四、为什么“非线性”是光计算的核心瓶颈

传播是线性的：

\[ U_2=HU_1 \]

相位掩膜也是线性的：

\[ U_2=DU_1 \]

连续很多层：

\[ U_L=H_LD_L\cdots H_1D_1U_0 \]

最终仍然等价于：

\[ \boxed{U_L=W_{\mathrm{eff}}U_0} \]

也就是说，如果没有非线性，无论堆多少线性层，本质上仍可合并成一个大线性变换。

普通神经网络真正强大的关键在：

\[ x_{l+1}=\sigma(W_lx_l) \]

其中 \(\sigma\) 是 ReLU、GELU、SiLU 等非线性函数。

探测器本身是非线性的

\[ \boxed{I=|U|^2} \]

但探测器会把 optical signal 转成 electrical signal，于是通常需要：

Optical ↓ Photodetector ↓ Electrical nonlinear ↓ DAC ↓ Modulator ↓ Optical

这会带来 O/E/O 转换的功耗、延迟和数据搬运开销。

这正是为什么“纯光深度生成模型”远比“纯光矩阵乘法”困难。

十五、采样理论与 FFT

实际数值模拟的是离散网格：

\[ U[m,n] \]

若网格大小 \(N\times N\)，像素间距为 \(\Delta x\)，则物理尺寸：

\[ L=N\Delta x \]

Nyquist 最大空间频率约为：

\[ \boxed{f_{\max}=\frac{1}{2\Delta x}} \]

如果传播产生的频率超过此范围，就会出现 aliasing。

为什么 FFT 是光学仿真的核心？

直接积分很慢，而利用卷积定理：

\[ U_z=U_0*h \]

可以改写为：

\[ \boxed{ U_z= \mathcal F^{-1} \left[ \mathcal F(U_0)H \right] } \]

复杂度从直接积分的极高代价，降低到 FFT 的 \(O(N^2\log N)\) 量级。

十七、Python 最小实验

实验 1：生成第一束数字光

import numpy as np
import matplotlib.pyplot as plt

N = 512
dx = 10e-6
wavelength = 532e-9

x = (np.arange(N) - N/2) * dx
X, Y = np.meshgrid(x, x)

w0 = 0.5e-3

U0 = np.exp(-(X**2 + Y**2) / w0**2)

plt.imshow(np.abs(U0)**2)
plt.title("Input intensity")
plt.show()

实验 2：Angular Spectrum propagation

def angular_spectrum(U, wavelength, dx, z):
    N = U.shape[0]

    fx = np.fft.fftfreq(N, d=dx)
    FY, FX = np.meshgrid(fx, fx)

    k = 2 * np.pi / wavelength

    argument = (
        k**2
        - (2*np.pi*FX)**2
        - (2*np.pi*FY)**2
    )

    kz = np.sqrt(argument.astype(np.complex128))
    H = np.exp(1j * kz * z)

    U_fft = np.fft.fft2(U)
    Uz = np.fft.ifft2(U_fft * H)

    return Uz
Uz = angular_spectrum(
    U0,
    wavelength,
    dx,
    z=0.1
)

plt.imshow(np.abs(Uz)**2)
plt.title("Propagated intensity")
plt.show()

实验 3：相位掩膜

phase = np.random.rand(N, N) * 2*np.pi

U1 = U0 * np.exp(1j * phase)

U2 = angular_spectrum(
    U1,
    wavelength,
    dx,
    0.1
)

plt.imshow(np.abs(U2)**2)
plt.title("Phase → interference → intensity")
plt.show()

这个实验验证一个关键事实：

\[ |U_1|^2=|U_0|^2 \]

也就是说 phase mask 前后的强度不变，但传播后强度分布发生巨大变化。

实验 4：孔径与 Fourier diffraction

a = 0.5e-3

U = (
    (np.abs(X) < a/2) &
    (np.abs(Y) < a/2)
).astype(float)

F = np.fft.fftshift(
    np.fft.fft2(U)
)

I = np.abs(F)**2

plt.imshow(np.log1p(I))
plt.title("Far-field diffraction")

实验 5：数字 4f low-pass filter

F = np.fft.fftshift(
    np.fft.fft2(U)
)

# 注意：真实代码应在频率坐标上构造 mask
H = np.zeros_like(F, dtype=float)

cy, cx = np.array(F.shape) // 2
radius = 40

Yg, Xg = np.ogrid[:F.shape[0], :F.shape[1]]
mask = (Xg-cx)**2 + (Yg-cy)**2 <= radius**2
H[mask] = 1

F_filtered = F * H

U_out = np.fft.ifft2(
    np.fft.ifftshift(F_filtered)
)

plt.imshow(np.abs(U_out)**2)
plt.title("Low-pass filtered output")
plt.show()
